# Travel Planner

Travel Planner — это Django-приложение для планирования путешествий.

Приложение позволяет:

- создавать поездки;
- указывать название поездки;
- выбирать страну и город;
- указывать даты начала и окончания поездки;
- указывать бюджет;
- просматривать список поездок;
- просматривать подробную информацию о поездке;
- редактировать и удалять поездки;
- вести список вещей для каждой поездки;
- отмечать вещи как собранные;
- удалять вещи из списка;
- выбирать город в зависимости от выбранной страны;
- искать страну и город в селекторах.

## Технологии

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
